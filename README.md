# 音频评分工具（MOS / SMOS）

一个 Python GUI 小工具，用于对多个模型的推理音频做主观评分（MOS / SMOS），
自动计算平均分与 95% 置信区间，并支持多人分评后合并汇总。

## 功能

- 打开「推理目录」：每个子文件夹视为一个模型，子文件夹内为同名音频
- 逐样本试听并打分（1–5 分），实时写入存档
- 音量可调、参考音频播放（用于 SMOS）
- 结果页自动计算各模型 **平均分 + 95% 置信区间**（t 分布），带柱状图+误差棒
- **盲测模式**：打乱模型顺序并隐藏模型名（显示为「样本 N」），每个样本重新随机，避免顺序/名称偏置
- 支持 **拆分存档** 分给多人，也支持 **合并存档** 汇总多人评分
- **记住上次设置**：目录、音量、评分类型、参考文件夹、窗口大小自动保存
- 结果可导出 **CSV** 与 **图表 PNG**
- 深色现代化界面

## 目录结构约定

```
inference_dir/
├── model_A/          # 模型 A 的输出
│   ├── sample_001.wav
│   ├── sample_002.wav
│   └── ...
├── model_B/
│   ├── sample_001.wav
│   └── ...
└── ref/              # （可选）参考音频，用于 SMOS
    ├── sample_001.wav
    └── ...
```

所有模型文件夹中**同名**的音频会被自动识别为待评样本。

## 安装

> 需要在**有图形界面和音频输出**的电脑上运行（要弹窗 + 听音频打分）。

### 方式一：一键脚本（推荐）

- **Windows**：双击 `run.bat`
- **Linux / macOS**：终端执行 `./run.sh`（首次可 `chmod +x run.sh`）

脚本会自动创建虚拟环境并安装依赖，之后直接启动。

### 方式二：手动安装

```bash
pip install -r requirements.txt
```

或使用 conda：

```bash
conda env create -f environment.yml
conda activate audio-scorer
```

## 运行

```bash
python main.py
```

## 使用流程

1. 点击「📂 打开推理文件夹」，选择推理目录
2. 选择评分类型（MOS 或 SMOS），必要时指定参考文件夹
3. 如需防偏置，勾选工具栏「盲测（打乱模型顺序）」
4. 在「🎧 评分」页逐样本试听打分，用「上一个/下一个」切换样本
5. 在「📊 结果」页查看统计与图表，可「导出 CSV」「导出图表」
6. 多人协作：每人各自评分并保存，最后一人用「🧩 合并存档」汇总

## 存档格式

存档为 JSON 文件，`ratings` 字段按 `样本 -> 模型 -> 分数（或分数列表）` 组织。
合并后的存档中同一（样本, 模型）会保留多份评分，统计时全部计入。

## 说明

- MOS：评整体音质 / 自然度
- SMOS：评与参考音频的相似度
